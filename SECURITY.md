# Security Policy

## Reporting a vulnerability

Please use GitHub private vulnerability reporting: open this repository's
**Security** tab and choose **Report a vulnerability**.

- Do **not** open a public issue for a vulnerability.
- Never include a real API key in your report — mask it (for example
  `dql_****`).

## Supported versions

The 0.1.x release line is supported with security fixes. Only the latest
published release is supported.
